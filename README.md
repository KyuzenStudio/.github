## 🏯 About Us

**Kyuzen Studio** is an independent software studio built on one conviction: the best way to truly understand technology is to **build it from zero** - no shortcuts, no abstractions hiding how things actually work.

We work across the entire computing stack - from silicon to the cloud:

| Domain | What We Build |
|--------|---------------|
| ⚙️ **Systems & Low-Level** | Operating systems, kernels, embedded, developer tooling |
| 🌐 **Web** | Frontend experiences & backend services, end to end |
| 📱 **Apps** | Cross-platform desktop & mobile applications |
| 🤖 **Machine Learning** | Models, inference engines, and intelligent systems |

## 🧭 Our Philosophy

> ### 🦀 **Everything will be Rust.**
>
> Memory safety without a garbage collector. Fearless concurrency. Zero-cost abstractions. Rust is not just our language of choice - it is the foundation of everything we build.

- **Build from scratch** - Understand every layer, don't just consume it.
- **Everything will be Rust** - One language, from bootloader to userland, backend to ML inference. Safe, fast, and honest.
- **Full-stack by principle** - The same care whether it's a kernel interrupt or a web API.
- **Learn in public** - Document the journey, the failures, and the discoveries.
- **Craftsmanship over speed** - Code that is clean, deliberate, and built to last.
- **First principles thinking** - Question every assumption; rebuild what doesn't make sense.

## 💻 Flagship Project

Beyond KyuzenOS, our repositories span web platforms, applications, and machine learning experiments - but this is where it all started:

<div align="center">

### ⚙️ KyuzenOS

*A Modern Operating System Built From Scratch*

</div>

**KyuzenOS** is a modern operating system built entirely from the ground up - bootloader, kernel, drivers, and userland - written in **Rust**. It is the embodiment of our philosophy: deep understanding through building our own foundations.

🔗 Docs & progress: **[os.kyuzenstudio.com](https://os.kyuzenstudio.com/en)**

| Layer | Focus |
|-------|-------|
| 🥾 **Bootloader** | Bare-metal boot process, UEFI/BIOS handoff |
| 🧠 **Kernel** | Memory management, scheduling, interrupt handling |
| 🔌 **Drivers** | Hardware abstraction layer |
| 🐚 **Userland** | Shell, utilities, and runtime environment |
