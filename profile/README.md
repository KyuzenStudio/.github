## About

Kyuzen Studio is an independent software studio. Our work is guided by a single principle: software is best understood by building it from first principles, rather than treating existing layers as black boxes.

We work across the computing stack:

| Domain | Scope |
|--------|-------|
| **Systems & Low-Level** | Operating systems, kernels, embedded firmware, developer tooling |
| **Web** | Frontend applications and backend services |
| **Applications** | Cross-platform desktop and mobile software |
| **Machine Learning** | Models, inference engines, and supporting infrastructure |

## Engineering Approach

- **Build from first principles.** Prefer understanding a layer over consuming it.
- **Rust as the primary language.** Memory safety without a garbage collector, combined with predictable performance and strong compile-time guarantees.
- **Consistency across the stack.** The same standards apply to kernel code and web services alike.
- **Work in public.** Development progress, design decisions, and failures are documented in our repositories.
- **Maintainability over velocity.** Code is written deliberately, with longevity in mind.

## Flagship Project: KyuzenOS

Our repositories cover web platforms, applications, and ML experiments, but the flagship is KyuzenOS - a modern operating system written entirely in **Rust**, from bootloader to userland.

Documentation and progress: **[os.kyuzenstudio.com](https://os.kyuzenstudio.com/en)**

| Layer | Responsibility |
|-------|----------------|
| **Bootloader** | Bare-metal boot process, UEFI/BIOS handoff |
| **Kernel** | Memory management, scheduling, interrupt handling |
| **Drivers** | Hardware abstraction layer |
| **Userland** | Shell, utilities, and runtime environment |
